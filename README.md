# FGO 抽卡（astrbot_plugin_fgo_gacha）

FGO模拟抽卡：在群内通过水群和签到获取圣晶石，并进行单抽/十连，支持从Mooncell自动更新数据。

适配 **AstrBot 4.28.x**，支持QQ官方机器人，自带 WebUI 设置页，配置保存在插件自己的 `config.json` 中，不依赖 `_conf_schema.json`。


## 功能

- **来发单抽 / 来发十连**：通过发送这两条指令，消耗圣晶石抽卡
- **圣晶石积分**：群消息自动加分，支持自定义分值、命令黑名单，默认关闭
- **每日签到**：发送`签到` 每日一次领取圣晶石，`看看存石` 查询余额
- **UP设定**：3/4/5★ 可自由设定卡池UP从者和礼装
- **国服卡池**：可按照已实装ID过滤卡池内容
- **剧情池**：可按照剧情池在卡池中加入剧情限定
- **素材抓取**：从 fgo.wiki 增量抓取从者与礼装，支持每日定时任务



## 准备素材

首次使用请打开插件设置页点击下方 **「立即增量抓取」** 获取素材图片。

> 抓取是增量的：已存在的文件会跳过，可反复执行。

## 命令

所有命令均在**群聊**中直接发送（无需前缀），文本需完全匹配。

| 命令 | 说明 | 消耗 |
| --- | --- | --- |
| `来发单抽` | 随机抽取 1 张 | 3 圣晶石（可配置） |
| `来发十连` | 抽取 11 张（10 连 + 1 赠）并拼成一张大图，含保底 | 30 圣晶石（可配置） |
| `签到` | 每天首次签到领取圣晶石 | 每日 1 次 |
| `看看存石` | 查询当前圣晶石余额 | 无 |

## 积分与签到（可配置）

| 行为 | 默认获得 |
| --- | --- |
| 普通文字消息 | +5 圣晶石 |
| 含图片的消息 | +10 圣晶石（图片优先，不与文字叠加） |
| 每日首次签到 | +30 圣晶石 |

- `不加分的命令` 中的文本不会获得文字积分（默认包含抽卡、签到、查石等命令）。
- 积分为 **按群隔离** 的账户，数据保存在 `plugin_data/astrbot_plugin_fgo_gacha/points.json`。
- **积分功能关闭时**：不再获得积分，`签到` 与 `看看存石` 停用；抽卡仍然可用，但**免费**，不扣石也不校验余额。已有余额会保留，重新开启后继续使用。

## 卡池与概率

卡池概率：

| 分类 | 基础概率 | 默认 UP 概率 |
| --- | --- | --- |
| 3★ 从者 | 40% | 4% |
| 4★ 从者 | 3% | 2.1% |
| 5★ 从者 | 1% | 0.8% |
| 3★ 礼装 | 40% | 8% |
| 4★ 礼装 | 12% | 4% |
| 5★ 礼装 | 4% | 2.8% |

- 未设置 UP 的分类 = 整块按普通随机抽取。
- 可自由修改UP概率（GPDS警告）
- 只做了十连保底，没做大保底


## 目录与数据

```text
AstrBot/data/plugins/astrbot_plugin_fgo_gacha/
├── main.py                  # 插件主逻辑
├── scrape_fgo.py            # fgo.wiki 素材抓取脚本
├── metadata.yaml
├── requirements.txt
└── pages/settings/          # WebUI 设置页
```

运行数据：

```text
AstrBot/data/plugin_data/astrbot_plugin_fgo_gacha/
├── config.json                # 插件配置
├── points.json                # 圣晶石 / 签到
├── gacha_count.json           # 抽卡次数统计
└── resources/                 # 抽卡素材（meta + image/chouka）
```

图片按文件名中的数字识别 ID，例如 `Servant001.jpg`、`礼装001.jpg`。自定义图片放进对应池目录即可参与抽卡（ID 需与 meta 对应才能被国服/剧情规则正确过滤）。

> 素材位于 `plugin_data/astrbot_plugin_fgo_gacha/resources/`。

## 常见问题

**抽卡提示「卡池图片缺失」**
`plugin_data/astrbot_plugin_fgo_gacha/resources/image/chouka/` 下没有可用图片。请在设置页执行「立即增量抓取」，或检查目录与文件名。

**十连报缺少 Pillow**
在 AstrBot 的 Python 环境执行 `pip install -r requirements.txt` 后重启。

**设置页一直加载 / 桥接超时**
先刷新页面；仍不行时重启 AstrBot。设置页需要 AstrBot 4.28+ 的插件页面桥接。

**UP 设置了却像没生效**
开启国服池时，ID 超过已实装上限的 UP 会自动视为未设置；另外请确认卡片星级与 UP 分类一致。
